# c4a-skill-evaluator

C4 技能提交自动评审器（EduSeed 挑战 C4A「技能自动评审」的产物）。

给定一个装满 C4 提交的文件夹，自动：

1. **采集**——递归扫描，按「作者拼音_C4_描述.扩展名」解析作者并分组；
2. **完整性检查**——核对 C4 五个必须交付物是否齐全；
3. **四条件质量评审**——按「可复用 / 可执行 / 可验证 / IO 明确」做信号命中规则打分；
4. **报告**——输出 Markdown 评审报告 + Excel 可开的 CSV 详表（含评审依据，非黑箱）。

---

## 快速上手

```bash
python3 skill-evaluator/scripts/evaluator.py <提交文件夹> --out 评审报告.md --csv 评审详表.csv
```

**零依赖**，仅用 Python 标准库（`os` / `re` / `csv` / `zipfile` / `tarfile` …）。

### 示例

```bash
git clone https://github.com/junyisong01-glitch/c4a-skill-evaluator.git
cd c4a-skill-evaluator

# 假设 _评审输入/ 里放了几位同学的 C4 提交
python3 skill-evaluator/scripts/evaluator.py _评审输入/ \
  --out 评审报告.md --csv 评审详表.csv
```

输出两件东西：

| 文件 | 内容 |
|---|---|
| `评审报告.md` | 总览排名表 + 逐作者五文件 ✅/❌ + 四条件判定 + 命中信号依据 + 综合分/评级 |
| `评审详表.csv` | 一作者一行，Excel 可开：排名/作者/完整数/完整性分/质量分/综合分/评级/四条件判定 |

## 输入约定

提交文件命名遵循 `姓名拼音_C4_内容描述.扩展名`，例如：

```
宋俊毅_C4_skill说明.md
宋俊毅_C4_demo.png
宋俊毅_C4_skill-evaluator.skill
```

也支持按作者分子目录的结构（递归扫描）。无法解析作者名的文件归入「_未分类」。

---

## 评审口径（两层）

### 第一层：五文件完整性（占综合分 40%）

必须交付物：Skill 说明 / 可执行内容 / Demo / 教学说明 / AI 日志。
完整性分 = 命中文件数 / 5。

### 第二层：四条件质量（占综合分 60%，各 0.25）

- **可复用**：有安装/环境说明、无硬编码绝对路径、注明平台、依赖可获取；
- **可执行**：含可运行代码/prompt/workflow、.skill 包结构有效、SKILL.md 含 frontmatter；
- **可验证**：有测试用例/示例、定义预期输出、demo 展示真实结果、成败标准清晰；
- **IO 明确**：有「输入 X → 输出 Y」一句话、明确输入/输出类型与格式、注明边界输入。

每个条件按「正信号命中数 − 负信号惩罚」映射为 ✅(1.0) / ⚠️(0.5) / ❌(0.0)，命中信号写入报告作为**评审依据**。

### 综合分与评级

```
综合分 = 完整性分 × 0.4 + 质量分 × 0.6
评级   = ≥0.8 A / ≥0.6 B / ≥0.4 C / 否则 D
```

## 边界（诚实说明）

- 本评审器是**规则引擎初筛**：判断「文件在不在、信号有没有」，不替代人工对内容质量的最终判断。适合初筛、互评一致性校准、助教批量预读。
- **不伪造证据**：信号命中列的是「真的匹配到了哪个关键词/模式」，没命中就是「—」。
- 对复杂/边界提交，建议先跑脚本得到初筛分与证据，再人工复核。
